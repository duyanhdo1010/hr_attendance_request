# HR Attendance Request

## Bài toán

Thêm chức năng request quên chấm công.

## Chức năng chính

- Tạo request chấm công.
- Có các loại request:
  - Quên check-in
  - Quên check-out
- Một request có thể có nhiều line quên chấm công cho nhiều ngày.
- Có các màn hình:
  - List view
  - Form view
  - Search view
- Có các button xử lý luồng:
  - Submit
  - Approve
  - Reject
  - Reset to Draft
- Có validation dữ liệu.
- Có phân quyền theo vai trò:
  - Employee
  - PM
  - DL
  - HR
- Có email thông báo ở các bước duyệt.
- Có wizard confirm khi reject, kèm lý do.
- Có deadline duyệt quên chấm công (quá deadline thì bôi đỏ ngoài list view).
